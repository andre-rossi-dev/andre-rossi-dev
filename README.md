## 🚀 Featured Projects

### 🏎️ ROSSI Pitwall — F1 25 Telemetry Monitor

A local Windows desktop application that reads **F1 25 UDP telemetry (2025 and 2026 formats)** and displays speed, gear, lap, session context, tyres, fuel, ERS, race position and time gaps.

Built with **Electron, React, TypeScript and Node.js**, with a separate simulation mode and automated tests.

**Status:** Technical Preview V0.3C-A — active development paused. No Windows installer is available.

[![View Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/andre-rossi-dev/rossi-pitwall)
